四大生物大分子

蛋白質、核酸、醣類、脂質——生命的化學積木。每一類分子都有對應的量測技術與資料形態，搞清楚這個對應，能避免「拿錯資料回答錯誤的問題」。

Proteins, nucleic acids, carbohydrates, lipids — life's chemical Lego. Each class maps to specific assays and data shapes; matching biology to measurement avoids "asking the wrong data the wrong question."

生命由四類大分子組成

所有生物大分子都是由小單體 (monomer) 聚合而成的聚合物 (polymer)。理解單體種類、鍵結方式、與功能的對應，就能解讀任何一份生物分子資料。

All biomolecules are polymers of small monomers. Knowing the monomers, bonds, and function lets you read any molecular dataset.

蛋白質

蛋白質：生命的工作分子

胺基酸 (amino acid) 結構：中心碳（α-C）連接胺基（-NH₂）、羧基（-COOH）、氫、與決定性質的側鏈 R。20 種標準胺基酸依 R 性質分為：非極性（A, V, L, I, M, F, W, P）、極性中性（S, T, N, Q, Y, C, G）、酸性（D, E）、鹼性（K, R, H）。胺基酸之間以肽鍵 (peptide bond) 連結成多肽鏈。

四級結構：一級（序列）→ 二級（α-螺旋、β-摺板，由氫鍵主導）→ 三級（單一肽鏈的 3D 摺疊）→ 四級（多條鏈組裝）。結構決定功能。

An amino acid has α-carbon connecting amino (-NH₂), carboxyl (-COOH), hydrogen, and a side chain R. The 20 standard amino acids group as: nonpolar (A, V, L, I, M, F, W, P), polar neutral (S, T, N, Q, Y, C, G), acidic (D, E), basic (K, R, H). They link via peptide bonds.

Four-level structure: primary (sequence) → secondary (α-helix, β-sheet, H-bond-driven) → tertiary (3D fold) → quaternary (multi-chain assembly). Structure dictates function.

Catalyze reactions, 10⁶–10²² speed-up. Classified by EC numbers (EC 1-7).

📘
快速回顧：蛋白質序列由 mRNA 翻譯而來，每三個核苷酸（codon）對應一個胺基酸。同一段 ORF 可有不同 isoform、PTM、亞細胞定位——這些差異無法從序列直接讀出，需 proteomics / 結構生物學補充。 Quick review: Protein sequence comes from mRNA — every codon (3 nt) encodes one amino acid. The same ORF can yield different isoforms, PTMs, and localizations — not readable from sequence alone, needs proteomics / structural biology.
🚀
進階補充（給 CS/ML 背景）：蛋白質序列空間 (20^L) 巨大但摺疊空間相對緊湊——AlphaFold 2/3、ESMFold 等模型透過 evolutionary coupling + 深度學習能從序列預測 3D 結構，準確度逼近實驗 (CASP15 中 GDT-TS > 90)。但動態構象、配體結合姿態、與 PTM 影響仍是開放問題。 Deep dive (for CS/ML readers): Sequence space (20^L) is huge but the folded manifold is relatively compact — AlphaFold 2/3 and ESMFold predict 3D structure from sequence with near-experimental accuracy (CASP15 GDT-TS > 90). Open problems: conformational dynamics, ligand poses, and PTM effects.
核酸

核酸：訊息分子

核苷酸 = 戊糖（pentose）+ 含氮鹼基（base）+ 磷酸基。DNA 用 deoxyribose；RNA 用 ribose（2'-OH 多一個氧）。鹼基分嘌呤（A, G）與嘧啶（C, T/U）；A 與 T/U 配對（2 個氫鍵），G 與 C 配對（3 個氫鍵）。

RNA 種類繁多：mRNA（編碼）、rRNA（核糖體骨架）、tRNA（攜帶胺基酸）、miRNA / siRNA（基因沉默）、lncRNA（長非編碼）、snoRNA / snRNA / piRNA / circRNA 等。它們在 RNA-seq 中的回收率因 library prep（polyA 富集 vs total RNA / RiboZero）大不相同。

A nucleotide = pentose + nitrogenous base + phosphate. DNA uses deoxyribose; RNA uses ribose (an extra 2'-OH). Bases split into purines (A, G) and pyrimidines (C, T/U); A pairs T/U (2 H-bonds); G pairs C (3 H-bonds).

RNA species are diverse: mRNA (coding), rRNA (ribosome scaffold), tRNA, miRNA / siRNA (silencing), lncRNA, snoRNA / snRNA / piRNA / circRNA. Their recovery in RNA-seq differs greatly by library prep (polyA enrichment vs total RNA / RiboZero).

醣類與脂質

常被忽略的兩類：醣與脂

🍯 醣類

從單糖（葡萄糖、半乳糖、岩藻糖）到多糖（澱粉、糖原、纖維素）。
關鍵應用：蛋白質糖基化 (glycosylation) 是最普遍的 PTM 之一（N-linked、O-linked），影響蛋白摺疊、運輸、辨識（如血型 ABO 系統、流感病毒受體）。糖蛋白佔細胞表面蛋白 > 50%。
資料：glycomics MS（PGC、HILIC）+ glycoproteomics（強胞固相提取與 fragment ion 計分）。

From monosaccharides (glucose, galactose, fucose) to polysaccharides (starch, glycogen, cellulose).
Why bioinfo cares: Glycosylation is one of the most common PTMs (N-linked, O-linked) — drives folding, trafficking, recognition (e.g. ABO blood groups, influenza receptors). Glycoproteins make up >50% of cell-surface proteins.
Data: glycomics MS (PGC, HILIC) + glycoproteomics (enrichment + fragment-ion scoring).

🧈 脂質

四大類：脂肪酸 (FA)、甘油脂 (TG, DG, MG)、磷脂 (PC, PE, PS, PI)、固醇類 (cholesterol, steroids)。
功能：膜、能量儲存、訊號（PIP3、DAG、ceramide）。膜脂組成決定流動性、cholesterol 含量決定 lipid raft 形成。
資料：LC-MS / shotgun lipidomics → 鑑定 LIPID MAPS 註解，需區分「class、subclass、acyl chain」三個層次。

Four classes: fatty acids, glycerolipids (TG/DG/MG), phospholipids (PC/PE/PS/PI), sterols (cholesterol, steroids).
Functions: membranes, energy storage, signaling (PIP3, DAG, ceramide). Membrane lipid composition controls fluidity; cholesterol drives lipid rafts.
Data: LC-MS / shotgun lipidomics → LIPID MAPS annotation at class / subclass / acyl-chain levels.
