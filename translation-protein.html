轉譯與蛋白質結構

mRNA 不是蛋白——從 codon 解讀、ribosome 工作、共轉譯摺疊、到 PTM 與亞細胞定位，每一步都會讓「相同 transcript 結果不同」。這也是 proteomics 與 RNA-seq 永遠對不上的原因。

mRNA isn't protein — codon decoding, ribosome action, co-translational folding, PTMs, and localization all make "same transcript, different outcome." Why proteomics and RNA-seq never fully agree.

轉譯機制

ribosome、tRNA 與密碼子

核糖體 (ribosome) 是 ribozyme（催化由 rRNA 主導），由大亞單位（60S，含 28S/5.8S/5S rRNA + 蛋白）與小亞單位（40S，含 18S rRNA）組成。小亞單位先結合 mRNA 並掃描 5'UTR 找 AUG（Kozak context）；大亞單位接合後形成 A、P、E 三個 tRNA 槽。

遺傳密碼 (genetic code)：64 個 codon = 61 個編碼 + 3 個終止 (UAA, UAG, UGA)；起始永遠是 AUG = Met。密碼有簡並性 (degeneracy)：同一胺基酸可由多個 codon 編碼，但生物對 codon 偏好不一（codon usage bias）→ 影響翻譯效率與蛋白摺疊。

三階段：initiation（eIF1-6 + cap binding → 40S 掃描 → 60S 結合）→ elongation（aminoacyl-tRNA 進 A site、peptide bond 形成、translocation）→ termination（release factor eRF1/3 辨識 stop codon）。每個 codon 約 60 ms，平均蛋白 50–100 殘基/秒。

The ribosome is a ribozyme (catalysis by rRNA), made of 60S (28S/5.8S/5S rRNA + proteins) and 40S (18S rRNA). The 40S binds mRNA, scans 5'UTR for AUG (Kozak); 60S joins to form A, P, E tRNA sites.

Genetic code: 64 codons = 61 sense + 3 stop (UAA, UAG, UGA); always starts at AUG = Met. The code is degenerate: synonymous codons exist, but organisms have codon usage bias affecting translation rate and folding.

Three phases: initiation (eIF1-6 + cap → 40S scanning → 60S joining) → elongation (aminoacyl-tRNA entry, peptide bond, translocation) → termination (release factor eRF1/3 at stop). ~60 ms per codon, ~50–100 aa/sec.

📘
快速回顧：tRNA 一端攜帶胺基酸，另一端 anticodon 與 mRNA codon 配對。aminoacyl-tRNA synthetase 負責把對的胺基酸接到對的 tRNA——這是遺傳密碼真正「物理實作」的環節。 Quick review: tRNAs carry an amino acid at one end and an anticodon at the other to pair with mRNA codons. Aminoacyl-tRNA synthetases attach the correct amino acid to the correct tRNA — the actual physical implementation of the genetic code.
🚀
進階補充：Ribo-seq（ribosome profiling）量到「ribosome 保護下的 28-32 nt mRNA 片段」，能定位每個 codon 的翻譯速率與 ribosome stalling、檢測 uORFs、評估 translation efficiency = ribosome density / mRNA。這是補足 RNA-seq → 蛋白豐度 的關鍵層。 Deep dive: Ribo-seq (ribosome profiling) captures 28–32 nt mRNA fragments protected by ribosomes — codon-level translation rate, stalling, uORF detection, translation efficiency = ribosome density / mRNA. The missing link between RNA-seq and protein abundance.
蛋白質摺疊

從一級序列到三維結構：摺疊與品管

Anfinsen 假說：原始序列含有摺疊所需的全部訊息（給定生理環境）。實際上摺疊由疏水核心崩塌、二級結構形成、域間裝配多階段並行，常伴隨分子伴侶 (chaperone)。

主要伴侶系統：Hsp70（單體摺疊）、Hsp60/GroEL（封閉空間摺疊）、Hsp90（受體、激酶成熟）、Hsp100（解聚集）、prefoldin（細胞骨架伴侶）。

品管失敗的後果：

  • ER stress / Unfolded Protein Response (UPR)：misfolded protein 聚積 → IRE1、PERK、ATF6 啟動 → 表達轉錄因子簽名（HSPA5/BiP, DDIT3/CHOP, ATF4, XBP1s）。
  • 聚集相關疾病：阿茲海默（Aβ、tau）、帕金森（α-synuclein）、亨丁頓（poly-Q）、ALS（TDP-43、SOD1）。
  • 蛋白質降解：ubiquitin-proteasome（K48-polyUb）或 lysosome/autophagy（K63-polyUb）。

Anfinsen's hypothesis: the native sequence carries all folding information (given physiological conditions). In practice, folding proceeds via hydrophobic core collapse, secondary structure formation, and domain assembly, assisted by chaperones.

Major chaperone families: Hsp70 (monomeric folding), Hsp60/GroEL (enclosed chamber), Hsp90 (receptor/kinase maturation), Hsp100 (disaggregation), prefoldin (cytoskeleton).

Failure consequences:

  • ER stress / UPR: misfolded protein accumulation → IRE1, PERK, ATF6 → signature TFs (HSPA5/BiP, DDIT3/CHOP, ATF4, XBP1s).
  • Aggregation diseases: Alzheimer's (Aβ, tau), Parkinson's (α-syn), Huntington's (poly-Q), ALS (TDP-43, SOD1).
  • Degradation: ubiquitin-proteasome (K48-polyUb) or lysosome/autophagy (K63-polyUb).

⚠️
使用 AlphaFold 結構的注意：(1) 每個殘基有 pLDDT 信心分數（<50 視為 disordered/不可信）；(2) 多域之間相對位置不可信（PAE matrix 必看）；(3) 結合的 ligand / cofactor / 動態構象 不會出現；(4) 突變對結構的影響不可直接從 AF2 預測。 Tips when using AlphaFold: (1) Each residue has a pLDDT confidence (<50 = disordered/unreliable); (2) inter-domain orientations are unreliable (always check the PAE matrix); (3) ligands, cofactors, dynamics not shown; (4) mutational effects can't be directly read from AF2.
