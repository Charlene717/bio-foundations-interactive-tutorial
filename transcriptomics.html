轉錄體學

RNA-seq 是當代生物學最常用的量測——但「RNA-seq」是一整族技術的代稱，每一種解析不同的生物學問題：bulk 平均、單細胞解析、空間定位、isoform 解析、長讀真實。

RNA-seq is the most common modern measurement — but "RNA-seq" is a family of technologies: bulk averages, single-cell resolution, spatial localization, isoform resolution, long-read truth.

標準化

從 raw count 到可比較的表達量

RPKM / FPKM / TPM：「每千鹼基每百萬 reads」的衍生量。TPM 推薦：先除長度再除總和，每樣本 TPM 加總 = 10⁶，跨樣本比較較可靠。RPKM/FPKM 因為先除總後除長度，加總不一定 = 10⁶，不適合跨樣本比較。

大多數 DE 分析（DESeq2, edgeR, limma-voom）使用 raw count + 內建大小因子（median-of-ratios、TMM）——不要用 TPM/FPKM 做 DE。

scRNA-seq 標準化：LogNormalize（CPM × 1e4 + log1p）為傳統；SCTransform / Pearson residuals 改用負二項回歸後的殘差，可消除 depth bias。Scran 在多樣本場景表現好。

RPKM / FPKM / TPM: "per kilobase per million reads" derivatives. TPM is preferred — divide by length first, then by total; per-sample TPM sums to 10⁶ allowing cross-sample comparison. RPKM/FPKM totals don't equal 10⁶, so they shouldn't be cross-compared.

For DE analysis (DESeq2, edgeR, limma-voom) use raw counts with internal size factors (median-of-ratios, TMM) — never use TPM/FPKM as DE input.

scRNA-seq normalization: LogNormalize (CPM × 1e4 + log1p) traditionally; SCTransform / Pearson residuals use NB-regression residuals to remove depth bias. Scran is robust for multi-sample.

⚠️
陷阱：RNA-seq 是「相對量」——若兩個 condition 之間有「全局表達上升」（例如 MYC 過表達使所有 transcript 都增加），標準化會「磨平」這個訊號（compositional bias）。可用 spike-in（ERCC, RUV）校正。 Pitfall: RNA-seq is relative. If two conditions differ in global RNA output (e.g., MYC overexpression boosts all transcripts), standard normalization erases this signal (compositional bias). Use spike-ins (ERCC, RUV) to correct.
差異表達

DE 分析的統計核心

DESeq2 (Love 2014)

負二項回歸（NB GLM）+ 經驗貝氏縮放離散度估計 + LFC shrinkage（apeglm）。最廣用，適合小樣本（2–10）。

Negative binomial GLM + empirical Bayes dispersion shrinkage + LFC shrinkage (apeglm). Most popular, robust at small N (2–10).

edgeR (Robinson 2010)

NB GLM + quasi-likelihood (QLF) + TMM 標準化。在大規模、需要詳細 contrasts 時靈活。

NB GLM + quasi-likelihood + TMM. Flexible for large designs with detailed contrasts.

limma-voom (Law 2014)

將 count 轉為 log-CPM + 估算每個 observation 的權重（voom），再套用 limma 的線性模型。適合大樣本與微陣列風格。

Converts counts to log-CPM with per-observation weights (voom), then limma's linear model. Best for large N or array-style data.

單細胞 DE 工具

Wilcoxon / FindMarkers（簡單）；MAST（hurdle 模型處理 dropout）；pseudobulk → DESeq2/edgeR（建議：把細胞依 sample/cluster aggregate 後當 bulk）—Squair 2021 指出 pseudobulk 假陽性最少。

Wilcoxon / FindMarkers (simple); MAST (hurdle for dropout); pseudobulk → DESeq2/edgeR — Squair 2021 shows pseudobulk has the fewest false positives.
