定序技術與基因組學

從 Sanger 一條讀 500–1000 bp，到 Illumina 數十億條 short reads，再到 PacBio HiFi 與 ONT 的 long-read——不同平台的吞吐、長度、錯誤模式，根本決定了你能回答什麼生物學問題。

From Sanger's 500–1000 bp reads to Illumina's billions of short reads to PacBio HiFi and ONT long reads — throughput, length, and error mode of each platform decide what biology you can answer.

WGS / WES / Panel

基因組學三種主要策略

🌐 WGS

覆蓋整個 3.1 Gb，含非編碼區、SV、CNV、線粒體。30x depth 約 90 Gb data/個體。價格降至 ~$200/genome（消費端）。

Covers entire 3.1 Gb, including non-coding, SVs, CNVs, mitochondria. 30× depth ~ 90 Gb/individual. Price ~$200/genome (consumer).

🧬 WES

富集 ~30 Mb 蛋白編碼區（capture probes），約佔 1% 基因組但藏 ~85% 致病變異。便宜、效率高，臨床診斷主力。

Captures ~30 Mb coding regions (~1% genome) but harbors ~85% disease variants. Cheap and efficient — clinical diagnosis workhorse.

🎯 Targeted panel

數十到數百個基因（e.g. 癌症 panel、HBOC panel）。極深覆蓋（500x+）可偵測低 VAF somatic 變異，是臨床腫瘤學首選。

Tens to hundreds of genes (e.g. cancer panel, HBOC panel). Very deep (500×+) — detects low-VAF somatic variants; clinical oncology first choice.

比對與召喚

從 FASTQ 到 VCF：標準流程

QC + trim

FastQC、MultiQC 檢視；fastp / Trimmomatic 去 adapter 與低品質尾端。

FastQC, MultiQC inspection; fastp / Trimmomatic to trim adapters and low-Q bases.

Alignment

BWA-MEM2 / bwa / Bowtie2（short）、minimap2 / Winnowmap（long）、STAR / HISAT2 / Salmon（RNA）。

BWA-MEM2 / Bowtie2 (short), minimap2 / Winnowmap (long), STAR / HISAT2 / Salmon (RNA).

Sort + duplicate marking

samtools sort + GATK MarkDuplicates / picard。PCR duplicate 是大問題（尤其低投入量 library）。

samtools sort + GATK MarkDuplicates / Picard. PCR duplicates are critical to flag (esp. low-input libraries).

Base recalibration + variant calling

GATK BQSR；germline: DeepVariant / HaplotypeCaller；somatic: Mutect2 / Strelka2。joint-genotyping for cohorts (GLnexus, GenomicsDB)。

GATK BQSR; germline: DeepVariant / HaplotypeCaller; somatic: Mutect2 / Strelka2. Joint genotyping for cohorts (GLnexus, GenomicsDB).

Annotation + filtering

VEP / ANNOVAR / SnpEff 加註；gnomAD MAF filter；ACMG / ClinVar 解讀。

VEP / ANNOVAR / SnpEff annotation; gnomAD MAF filter; ACMG / ClinVar interpretation.

圖譜基因組

從線性參考到 pangenome graph

使用單一線性參考有 reference bias——非歐裔變異在參考上不存在 → reads 無法比對 → 召喚遺漏。HPRC pangenome (2023) 用 47 個多倍體個體構建圖譜基因組，工具：minigraph / vg / Giraffe / pggb。可顯著降低 SV 與 indel miss rate。

新一代分析範式：用 graph genome 比對 → 在 reference path 上呼叫變異，未來臨床基因組分析的標準路線。

A single linear reference has reference bias — non-European variants absent in reference → reads fail to align → call missed. The HPRC pangenome (2023) uses 47 diploid individuals; tools: minigraph / vg / Giraffe / pggb. Substantially reduces SV / indel miss rates.

Emerging paradigm: align to graph genome, call variants on the reference path — likely the future of clinical genomics.
