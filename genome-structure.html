基因組結構與註解

人類基因組 3.1 Gb 中只有 ~1.5% 是蛋白編碼——剩下 98.5% 並非「垃圾 DNA」。GENCODE / Ensembl / RefSeq 等註解資料庫定義了基因組裡每個位置代表什麼。

Only ~1.5% of the 3.1 Gb human genome is protein-coding — the other 98.5% is not "junk." GENCODE / Ensembl / RefSeq annotations define what each genomic position represents.

基因結構

一個真核基因的解剖

典型基因結構：啟動子 → 5'UTR → exon 1 → intron 1 → exon 2 → ... → 3'UTR → polyA site。CDS（編碼區）通常從 5'UTR 後第一個 AUG 開始，到 stop codon 為止。Exon 1 中常見 cap、intron 中可有 enhancer、3'UTR 包含 miRNA 結合位點。

Typical structure: promoter → 5'UTR → exon 1 → intron 1 → exon 2 → ... → 3'UTR → polyA site. CDS starts at the first AUG after the 5'UTR and ends at the stop codon. Exon 1 often contains the cap; introns can carry enhancers; 3'UTR holds miRNA binding sites.

基因組組成

人類基因組 3.1 Gb 怎麼分配？

蛋白編碼基因占 ~1.5%；其他包括重複序列（~50%）、調控元素、ncRNA、未註解區。

Protein-coding ~1.5%; the rest: repeats (~50%), regulatory elements, ncRNAs, unannotated.

🧬 蛋白編碼基因

GENCODE v45 標註約 19,432 個蛋白編碼基因；平均含 ~10 個 exons。意外地少——比線蟲多不了多少。複雜度來自 isoforms、PTM、調控。

GENCODE v45 lists ~19,432 protein-coding genes, avg ~10 exons. Surprisingly few — not much more than C. elegans. Complexity comes from isoforms, PTMs, regulation.

🪢 ncRNA

lncRNA、miRNA、snoRNA、snRNA、piRNA、tRNA、rRNA、circRNA——數量遠超蛋白編碼基因。

lncRNA, miRNA, snoRNA, snRNA, piRNA, tRNA, rRNA, circRNA — far outnumber coding genes.

🔁 重複元素

LINE-1 (~17%)、SINE/Alu (~11%)、LTR/ERV (~8%)、衛星 DNA、簡單重複。其中 transposable elements 可被重新活化（如 LINE-1 在癌症）。

LINE-1 (~17%), SINE/Alu (~11%), LTR/ERV (~8%), satellite DNA, simple repeats. Transposable elements can reactivate (e.g. LINE-1 in cancer).

🎛️ 調控元素

ENCODE / Roadmap / cCRE 標註約 ~1M 候選順式調控元件（包含 enhancers, promoters, CTCF sites, silencers）。是 GWAS 變異功能解讀的關鍵。

ENCODE / Roadmap / cCRE annotate ~1M candidate cis-regulatory elements (enhancers, promoters, CTCF sites, silencers) — key to interpreting GWAS variants.

👻 偽基因

類似真基因但通常失去功能。RNA-seq 上 reads 可能比對到 paralog 偽基因，造成定量誤差。某些 pseudogenes 仍有調控功能（如 PTENP1 海綿 miRNA）。

Resemble real genes but typically nonfunctional. RNA-seq reads may map to paralogous pseudogenes — a quantification trap. Some (e.g. PTENP1) still regulate (miRNA sponging).

❓ 未註解

每年新註解 RNA、enhancer、small ORFs（smORFs / micropeptides）持續更新。T2T-CHM13（2022）首次提供完整 telomere-to-telomere 組裝，填補 8% 缺口。

New RNAs, enhancers, small ORFs (smORFs / micropeptides) added yearly. T2T-CHM13 (2022) closed the remaining 8% gap with a complete telomere-to-telomere assembly.

⚠️
常見陷阱：染色體命名前綴 chr 在 UCSC / Ensembl 之間不一致（UCSC 用 chr1, Ensembl 早期版用 1）。混用會導致比對失敗，請統一一個風格並用 seqlevelsStyle()（R）或自訂腳本轉換。 Common pitfall: The chr prefix differs between UCSC (chr1) and earlier Ensembl (1). Mixing causes alignment failures — pick one style and normalize with seqlevelsStyle() (R) or scripts.
