基因表達調控

每個基因在何時、何處、多少量表達——是由轉錄因子、染色質可及性、增強子-啟動子互動、非編碼 RNA 與蛋白穩定性多層調控的結果。這層調控才是「不同細胞型態的本質」。

When, where, and how much a gene is expressed reflects TFs, chromatin accessibility, enhancer-promoter contacts, ncRNAs, and protein stability — multi-layer regulation that is the essence of cell-type identity.

調控層級

基因表達的七層調控

1. 染色質狀態

Heterochromatin 抑制 / euchromatin 開放。由 ATP-dependent remodelers（SWI/SNF, ISWI, CHD, INO80）與 histone modifiers 動態調整。對應實驗：ATAC-seq、DNase-seq、MNase-seq、ChIP-seq、CUT&RUN/Tag。

Heterochromatin silences; euchromatin permits. Dynamically tuned by ATP-dependent remodelers (SWI/SNF, ISWI, CHD, INO80) and histone modifiers. Assays: ATAC-seq, DNase-seq, MNase-seq, ChIP-seq, CUT&RUN/Tag.

2. 轉錄因子

人類約 1,600 個 TFs，以 DBD (zinc finger / bHLH / homeobox / leucine zipper...) 辨識 6-20 bp 短序列 motif，常與 co-activator / co-repressor 形成複合物。對應實驗：ChIP-seq、CUT&RUN、ChIP-exo、SELEX、in-vitro motif（JASPAR）。

~1,600 human TFs use DBDs (zinc finger / bHLH / homeobox / leucine zipper) to bind 6–20 bp motifs, often with co-activators/repressors. Assays: ChIP-seq, CUT&RUN, ChIP-exo, SELEX, in-vitro motifs (JASPAR).

3. Enhancer-Promoter 互動

遠端 enhancer 透過 chromatin looping 與 promoter 接觸（由 cohesin/CTCF + Mediator 介導）。同一 TAD 內 contacts 較強。對應實驗：Hi-C、Micro-C、capture-Hi-C、HiChIP、4C。

Distal enhancers contact promoters via chromatin loops (cohesin/CTCF + Mediator); intra-TAD contacts dominate. Assays: Hi-C, Micro-C, capture-Hi-C, HiChIP, 4C.

4. DNA 甲基化

哺乳類 5mC 主要在 CpG，promoter CpG island 高甲基化 → 抑制；gene body 甲基化 → 與活躍轉錄共存。對應實驗：WGBS、RRBS、EM-seq、enhanced 5hmC（TAB-seq）、Nanopore native methylation。

5mC mainly at CpG in mammals; promoter CpG-island methylation silences; gene-body methylation often coexists with active transcription. Assays: WGBS, RRBS, EM-seq, TAB-seq, Nanopore native methylation.

5. 後轉錄調控

RBPs 控制 splicing、stability、localization、translation；miRNA / siRNA 切割或翻譯抑制；m6A / m5C / ψ 修飾改變 RNA 命運。對應實驗：CLIP / eCLIP / iCLIP（RBP 結合）、smallRNA-seq、m6A-seq / MeRIP-seq、Nanopore RNA direct。

RBPs control splicing/stability/localization/translation; miRNAs/siRNAs cleave or block translation; m6A / m5C / ψ alter RNA fate. Assays: CLIP / eCLIP / iCLIP, smallRNA-seq, m6A-seq / MeRIP-seq, Nanopore direct RNA.

6. 轉譯效率

uORFs、IRES、cap-dependent vs cap-independent initiation、ribosome stalling 控制 mRNA → 蛋白的速率。對應實驗：Ribo-seq、polysome profiling。

uORFs, IRES, cap-dependent vs cap-independent initiation, ribosome stalling tune the mRNA → protein flux. Assays: Ribo-seq, polysome profiling.

7. 蛋白穩定性

Ubiquitin-proteasome / autophagy 控制蛋白半衰期；訊號 peptide / NLS / mitochondrial targeting 決定定位。對應實驗：SILAC pulse-chase、APEX 鄰近標記、proximity-MS。

Ubiquitin-proteasome / autophagy tune protein half-life; signal peptides / NLS / mitochondrial targeting decide localization. Assays: SILAC pulse-chase, APEX proximity labeling, proximity-MS.

調控網絡

從 TF–target 到 GRN

Gene Regulatory Network (GRN)：以 TF 為節點、調控關係為邊的有向圖。常用推論方法：

  • SCENIC / pySCENIC：在 scRNA-seq 上以共表達 + motif enrichment 推 regulon（TF + targets）。
  • CellOracle：結合 scATAC-seq + scRNA-seq，可預測 TF KO 後的細胞狀態變化。
  • Pando / FigR / DIRECT-NET：multi-omics GRN inference。
  • GENIE3 / GRNBoost2：以隨機森林 / GBM 推 TF-target。

GRN 的網絡 motif（feed-forward loop、negative feedback、bistable switch）決定動態行為——細胞命運決定、發育時鐘、應激反應都映射到這些 motif 上。

Gene Regulatory Network (GRN): directed graph with TFs as nodes and regulatory edges. Common inference methods:

  • SCENIC / pySCENIC — co-expression + motif enrichment on scRNA-seq → regulons (TF + targets).
  • CellOracle — combines scATAC + scRNA to predict in-silico TF perturbation outcomes.
  • Pando / FigR / DIRECT-NET — multi-omics GRN inference.
  • GENIE3 / GRNBoost2 — random-forest / GBM TF-target inference.

Network motifs (feed-forward loop, negative feedback, bistable switch) drive dynamics — cell-fate decisions, developmental clocks, and stress responses map onto these motifs.

🌳 從表達差異到調控機制

Q1:
觀察到 cluster X 的 gene G 高表達 → 上游 promoter 是否開啟？ → 查 scATAC-seq peak 與 ATAC bigwig。
Q2:
哪些 TF 可能驅動？ → 在 open peak 上做 motif enrichment（chromVAR / HOMER）。
Q3:
是否有 distal enhancer 互動？ → 查 HiChIP / capture-Hi-C 或 ABC model。
Q4:
蛋白層也有變化嗎？ → 整合 proteomics、PTM 數據；mRNA up 但蛋白不變常見於 TE 或 stability 變化。
Q1:
Gene G high in cluster X → is the upstream promoter open? → Check scATAC peak / ATAC bigwig.
Q2:
Which TFs likely drive it? → Motif enrichment on open peaks (chromVAR / HOMER).
Q3:
Distal enhancer contacts? → Check HiChIP / capture-Hi-C or ABC model.
Q4:
Change at protein level? → Integrate proteomics / PTMs; mRNA-up but protein-unchanged often = TE or stability change.
