細胞週期、分裂與訊號傳遞

細胞何時分裂、何時死亡、如何回應外部訊號——這些動態決定了組織恆定、發育、癌症與藥物反應。對應到分析時，是 cell-cycle score、pathway enrichment、藥理基因組學等工具。

When cells divide, die, and respond to signals defines tissue homeostasis, development, cancer, and drug response. Analysis-side: cell-cycle scoring, pathway enrichment, pharmacogenomics.

細胞週期

G1 → S → G2 → M：四階段與檢查點

四階段：G1（生長、合成準備）→ S（DNA 合成）→ G2（再生長、紡錘體準備）→ M（mitosis：prophase, prometa, meta, ana, telo + cytokinesis）。非分裂細胞進入 G0（靜止）。

核心調控：cyclin（D, E, A, B）+ CDK（CDK4/6, CDK2, CDK1）週期性活化。Rb 磷酸化釋放 E2F → 轉錄 S phase 基因。

檢查點：G1/S（DNA 損傷 → p53 → p21）、G2/M（ATR/ATM → CHK1/2 → CDC25）、Spindle assembly（不正確配對 → MAD2/BUB → 防止 anaphase）。失調是癌症最普遍的特徵。

Four phases: G1 → S (DNA synthesis) → G2 → M (mitosis: prophase, prometaphase, metaphase, anaphase, telophase + cytokinesis). Non-dividing cells enter G0.

Core regulation: cyclin (D, E, A, B) + CDK (CDK4/6, CDK2, CDK1) phasic activation. Rb phosphorylation releases E2F → transcribes S-phase genes.

Checkpoints: G1/S (DNA damage → p53 → p21), G2/M (ATR/ATM → CHK1/2 → CDC25), spindle assembly (improper attachment → MAD2/BUB → prevents anaphase). Disruption is a near-universal cancer hallmark.

💡
scRNA-seq 應用：Seurat::CellCycleScoring 用 Tirosh et al. 2016 的 S/G2M marker 集合估算每個細胞的週期分數，可用 regression out 來避免 cluster 被 cycle 干擾，或直接以週期作為分析變數。 scRNA-seq tip: Seurat::CellCycleScoring uses Tirosh et al. 2016 S/G2M markers to score each cell — regress out to prevent cycle-driven clusters, or use cycle as a covariate.
細胞死亡

多種「死法」對應不同的分析簽名

Apoptosis

程序性、不引發發炎；caspase-3/8/9，BCL2 家族（pro vs anti-apoptotic）。signature：CASP3, BAX, BAK1, BID 上調；BCL2 下調。

Programmed, non-inflammatory; caspase-3/8/9, BCL2 family. Signature: CASP3, BAX, BAK1, BID up; BCL2 down.

Necroptosis

RIPK1/3-MLKL 介導，引發發炎。signature：MLKL、RIPK3 表達/磷酸化。

RIPK1/3-MLKL-mediated, inflammatory. Signature: MLKL, RIPK3 expression/phosphorylation.

Pyroptosis

caspase-1/11、GSDMD（gasdermin）成孔。signature：NLRP3, AIM2 inflammasome、IL-1β/IL-18 釋放。

Caspase-1/11, GSDMD-mediated pore. Signature: NLRP3, AIM2 inflammasome, IL-1β/IL-18 release.

Ferroptosis

鐵依賴的脂質過氧化引發；signature：GPX4 下調、ACSL4 / PTGS2 上調、lipid ROS。

Iron-dependent lipid peroxidation. Signature: GPX4 down, ACSL4 / PTGS2 up, lipid ROS.

Autophagy

不一定致死；LC3-I → LC3-II、ATG5/7/12 介導。可生存或進入 autosis 死亡。

Not always lethal; LC3-I → LC3-II, ATG5/7/12 mediated. Can promote survival or autosis.

Senescence

持久 G1 停滯、抗 apoptosis。signature：CDKN2A (p16), CDKN1A (p21), SASP 細胞因子 (IL6, IL8, CXCL1...) — 不是死亡但常被誤判。

Permanent G1 arrest, apoptosis-resistant. Signature: CDKN2A (p16), CDKN1A (p21), SASP cytokines (IL6, IL8, CXCL1...) — not death but easy to misread.
